# Folder Images - Public

Taruh gambar static di sini yang ingin diakses langsung via URL.

## Cara Menggunakan:

```tsx
// Di komponen React, gunakan path absolute dengan diawali /
<img src="/images/nama-gambar.jpg" alt="Deskripsi" />
```

## Contoh:
- Logo website
- Favicon
- Gambar yang tidak perlu dioptimasi
- Gambar yang digunakan di HTML langsung
