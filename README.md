# Portfolio React

Portfolio website yang dibangun dengan React + TypeScript + Vite.

## 🚀 Memulai

### Instalasi Dependencies
```bash
npm install
```

### Menjalankan Development Server
```bash
npm run dev
```
Aplikasi akan berjalan di `http://localhost:3000`

### Build untuk Production
```bash
npm run build
```

### Preview Build Production
```bash
npm run preview
```

## 📁 Struktur Project

```
Portofolio/
├── public/          # File static (images, icons, dll)
├── src/
│   ├── App.tsx      # Komponen utama
│   ├── App.css      # Styling untuk App
│   ├── main.tsx     # Entry point React
│   └── index.css    # Global styles
├── index.html       # HTML template
├── vite.config.ts   # Konfigurasi Vite
└── tsconfig.json    # Konfigurasi TypeScript
```

## 🛠️ Teknologi yang Digunakan

- **React** - Library UI
- **TypeScript** - Type safety
- **Vite** - Build tool yang cepat
- **CSS** - Styling

## 📝 Catatan

Project ini sudah dikonfigurasi dan siap digunakan. Anda bisa mulai mengembangkan portfolio dengan menambahkan komponen-komponen baru di folder `src/`.
